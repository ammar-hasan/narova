# Narova 0.28 creativity A/B

Date: 2026-08-08

Model: `gpt-5.6-sol`

Runs: 8 rendered pilots (2 briefs × with/without Narova guidance × 2 independent runs)

## Question

Does Narova's authoring guidance make the same capable model attempt more
distinctive work than a minimal renderer contract alone?

This was deliberately not a benchmark platform. The existing `music-only` and
`shader-piece` adversarial briefs were used. Every run received the same model,
brief, JSON artifact contract, deterministic renderer, and 8–12 second pilot
limit. The treatment condition additionally received Narova's skill and creative
direction guidance. All configs and pilot frames were generated independently.

## Observed results

| Signal | Without Narova | With Narova | Reading |
|---|---:|---:|---|
| Valid, rendered pilots | 4/4 | 4/4 | Both conditions could use the renderer |
| Narration added against the brief | 0/4 | 0/4 | No difference |
| `captions: false` explicit | 2/4 | 4/4 | Narova improved intent compliance |
| Raw `threeModule` used | 4/4 | 4/4 | No escape-hatch avoidance; also severe medium convergence |
| Scene count | four 1-scene pilots | four 1-scene pilots | Complete convergence |
| Duration | four 10s pilots | four 10s pilots | Complete convergence |
| Centered/safe-layout framing | 0/4 | 0/4 | The raw canvas was used in both conditions |
| Near-black / visually unproven pilots | 2/4 | 1/4 | Technical success did not guarantee visible evidence |

Conceptually, the music runs all converged on violet/cyan shader fields with
names such as “Chromatic Tides” or “Chromatic Tidal Field.” The shader runs all
converged on a central singularity/event-horizon metaphor. The guided runs were
not meaningfully more diverse and did not attempt a medium the unguided runs
avoided. In this sample, capability awareness improved explicit configuration
choices but did not by itself create imagination.

Direct frame inspection mattered. Three contact sheets were effectively
near-black even though config validation, synthesis, composition, and snapshot
rendering all succeeded. That is exactly the failure mode a pilot is meant to
catch.

## Product decisions from the evidence

1. Ambitious work now defaults to 2–3 *small, orthogonal proof branches* with
   rationale, followed by one selection and one expansion. Independent samples
   alone can repeat the same latent default.
2. `creative-brief.md` is medium-neutral: intent, unusual hypothesis,
   representation, temporal behavior, evidence, and rejection criteria come
   first. Camera, depth, and lighting are conditional.
3. `narova branch save <name> --rationale "..."` requires rendered frames and
   preserves a hash-bound proof bundle—resolved config, manifest, timings,
   contact sheets, every audited frame—and an editable release snapshot whose
   complete file set is hashed. Current source assets are rehashed at save time,
   and the durable proof directory must match its exact recorded inventory.
   Stale frames, edited source, extra artifacts, or an orphaned snapshot cannot
   satisfy the release gate.
4. `narova shots --motion --proof` rejects a pilot when at least 75% of sampled
   frames are near-black or no frames exist. It remains opt-in because deliberate
   darkness can be valid; normal shot review still requires judgment.
5. The experiment remains runnable at
   `tool/evals/live-creativity-ab.js`. It generates pilots only and
   keeps outputs outside the repository unless `--out` is supplied.

## Limits

Eight pilots and two briefs are enough to expose convergence and workflow
failures, not to establish a general creativity score. The baseline still knew
the minimal Narova-compatible artifact contract so both conditions could be
rendered identically. Future reruns should vary model seeds and include briefs
whose best medium is not named in the contract, while staying small.
